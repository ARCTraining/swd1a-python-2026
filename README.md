# SWD1a Introduction to Programming in Python

This course introduces the foundations of programming using the python language. It has been written for researchers at the University of Leeds who plan to use python for data science or research software development.

## Learning outcomes

After completing this course, learners will be able to,

+ Recognise opportunities to use python to automate simple tasks and work with data.
+ Develop and run python code to solve simple problems and explore datasets.
+ Identify, interpret and fix common programming errors using error messages and debugging techniques.
+ Compare alternative solutions to a problem, considering aspects of code quality such as readability, maintainability and testability.

## Topics

The course covers the following topics:

+ Introduction to Python syntax, variables and conventions
+ Structuring data with lists and dictionaries
+ Controlling program flow (if statements and loops)
+ Using modules and packages to extend Python
+ Reading and working with research data (CSV, JSON and other file formats)
+ Exploring and manipulating tabular data with pandas
+ Creating simple visualisations from data
+ Writing functions for reusable, testable code
+ Understanding error messages and debugging effectively
+ Finding help: documentation, examples and AI-assisted learning

## Pre-requisites

The course assumes no prior knowledge of programming or python environments.

All exercises can be completed using a cloud-based IDE such as [Google Colab](colab.research.google.com) - there is no need to install python locally for this course.
